# AMAZINE

![AMAZINE](src/assets/Amazine_Logo_Simbolo_Tipografia.png)

Site da primeira Feira de Zines de Macapá. A AMAZINE valoriza e faz circular a produção literária e artística independente de Macapá a partir de fanzines.

Construído com [Astro](https://astro.build/) e TypeScript.

## Comandos

| Comando          | Ação                                   |
| ---------------- | -------------------------------------- |
| `pnpm install`   | Instala as dependências                |
| `pnpm dev`       | Inicia o servidor de desenvolvimento em localhost:4321 |
| `pnpm build`     | Gera o site de produção em ./dist      |
| `pnpm preview`   | Visualiza o build de produção          |

## Estrutura

```
src/
  assets/      Imagens e documentos
  components/  Componentes Astro reutilizáveis
  data/        Dados da galeria
  layouts/     Layouts de página
  pages/       Rotas do site
```
